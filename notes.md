# Spring Data JPA Notes
Spring Data is the module that allows us to manage our database and queries. It is a collection of tools to streamline our entities, tables and queries.

- Spring Data → entrypoint for utilizing Spring to manage DB data
- Java Persistence API JPA → tools to manage data (more interfaces than implementation)
- Hibernate -> ORM that can implement JPA functionality
